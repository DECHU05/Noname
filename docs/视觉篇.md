# CRTC 智能机器人小车项目日志 - 视觉篇

视觉模块的目标是识别场地上的两色方块并把坐标交给主控：白色方块（能量单元）与黄色方块（能量核心），规格为 30mm 立方体、内部镂空，标注时按外轮廓整体框选、孔洞不另标。场地上方块的高度并不统一，第一版只处理车前方、同一平面上的方块，把标定范围限定在平地近距离抓取。

## 一、方块识别与坐标输出

> 📅 10月11日-10月12日

硬件采用 K230D 视觉开发板与配套摄像头模块，与 STM32 之间走 **UART 有线通信**（TX 接 RX、RX 接 TX、共地）。分工是：K230 负责采图、推理、目标筛选和坐标输出；STM32 负责底盘速度、舵机时序和入仓确认。

代码以开源项目 hyper152/K230（电赛钢球检测）为骨架改造，保留它已经跑通的板端推理、模型转换、串口通信和日志做法，把“一维轨道位置”换成“台面二维坐标 + 抓取请求应答流程”。主要改动：

*   位置解算：原来的轨道刻度函数换成单应矩阵解算，用 9 点标定生成矩阵，输出台面物理坐标；
*   发送策略：不再每帧都发位置，改为“连续 N 帧位置不抖”才判定目标锁定，避免坐标抖动直接驱动机械臂；
*   通信流程：新增抓取状态机——发 TARGET → 等 ACK → 等 DONE → 冷却，带超时、重发去重，并区分单次与连续两种模式，防止机械臂重复执行；
*   标定模式：双击 K0 进入标定，屏幕叠加台面网格，串口打印 `CALIB,u,v`；
*   日志扩展：增加 `x_mm, y_mm, angle_deg, seq, note` 和串口收发原文，方便回看联调过程。

白色方块与白色地胶颜色接近、容易混淆，车体、线缆和夹爪也需要作为负样本覆盖；另外 YOLO 的检测框是轴对齐矩形，给不出方块的旋转角度，两指夹爪对姿态敏感时需要另做角度估计。

## 二、摄像头安装与标定

> 📅 10月11日-10月12日

安装方案定为**车头刚性前伸支架、镜头光轴垂直朝下**，视野覆盖夹爪前方的定位区域，并保留夹爪入口作为位置参照。相机不跟随夹爪运动。这个视角只覆盖局部工作区，需要操作手先把方块带进画面，不能靠它观察远处目标。

支架前伸量和高度要同时满足三件事：车体不挡住工作区、夹爪全行程不遮挡视野、以及过桥时的净空要求。固定后相机的安装高度、前伸距离、垂直度、分辨率和镜像设置都要记录下来，改动任意一项都需要重新标定。

标定用同规格的 30mm 方块在多个已知位置采集：下视理想情况下取外轮廓框中心，记录实际能稳定抓取的位置作为参考点，用像素误差 `e_u`、`e_v` 控制对准与接近。顶面与地面高度不同，像素尺度也不同，不能直接套用地面网格的比例；当前没有深度信息，所有目标都按躺在同一高度的台面处理。

车头加装视觉模块会让重心过于前倾——K230D 自重较大，安装位置还在推敲。

## 三、模型训练与部署

> 📅 10月13日-10月18日

链路是 PC 训练 YOLO 得到 `.pt`，导出 ONNX，再用 nncase 编译成 K230 上运行的 `.kmodel`。类别定义为 `0: white_cube`、`1: yellow_cube`，数据集按采集场次划分训练 / 验证 / 测试，编号相同的图片与标签一一对应，空场景保留空标签文件。

这里踩了一个版本坑：板子固件自带的 nncase 运行时是 **2.9.0**，而参考文章里写的是 2.11.0，**两边编出来的 kmodel 不通用**——用 2.11 编的拷到板子上会加载失败。所以转换工具链统一改用 2.9.0。

数据集目前用白方块训练，黄方块样本后续再补。

10 月 16 日至 18 日继续围绕识别精度做迭代：样本侧补充白方块在不同光照、不同摆放姿态下的覆盖，并把车体、线缆、夹爪这类易混淆对象纳入负样本；后处理侧调整置信度与筛选阈值，压低白方块与白色地胶之间的误检。

## 四、一键辅助抓取方案

> 📅 10月15日-10月18日

机械臂侧的抓取动作序列（抬起 / 悬停 / 下压 / 闭合 / 放置）由 STM32 实现，视觉只负责给出目标与坐标。视觉模块单独调试已经基本完成，但**与单片机的串口连接还有问题**，这是下一步要解决的重点；串口打通之后，坐标交给 STM32，由主控根据数据调整舵机完成抓取，目前流程还没有联调。

视觉模块目前仍在单独调试，受串口未打通和重心布置的限制，**这一部分在中期考核前无法完全实现**，进度推进到此为止。

多目标场景下目前只抓一个——优先跟随已锁定的目标，否则取置信度最高的；抓取失败的重试策略只有“报警告 + 冷却后再来一次”，没有换角度再夹这类高级策略。

由于视觉识别受现场光线、角度等不确定因素影响较大，团队采取保守策略：调校顺利、识别稳定则作为进阶功能展示，实际场地测试不稳定则退回纯 PS2 手柄手动控制，确保基础抓取功能不受影响。
