# Noname

**CRTC-Noname战队中期考核日志**

## 项目介绍

该项目主要记录了重庆大学2026CRTC赛事中Noname战队的机器人开发日志与源文件。我们基于“抓取并获得更多能量块”的目的，分为电控与视觉、机械两组，制作了三辆遥控战车。每辆参赛战车分别由遥控功能、驱动功能、抓取功能、其他功能四个板块。在另外两个文档中，我们会按功能分类编写日志。

## 机器人简介

参赛机器人以 STM32F103C8T6 为主控，采用麦克纳姆轮底盘与六舵机机械臂，通过 PS2 无线手柄遥控，在比赛场地内收集并携带能量单元与能量核心。

## 主要配置

| 部分 | 方案 |
| --- | --- |
| 主控 | STM32F103C8T6 核心板 |
| 底盘 | 4 个 TT 马达 + 麦克纳姆轮（60mm 胶轮方案研发中） |
| 电机驱动 | 2 片 DRV8833 |
| 机械臂 | 6 个 SG90 舵机（三舵机两杆结构已定型，尚未投用） |
| 舵机驱动 | PCA9685 十六路 PWM 驱动板 |
| 遥控 | PS2 无线手柄，软件 SPI（PB12~PB15） |
| 供电 | 一组 7.4V 18650 电池组，板载 XL4015 分路降压 |
| 视觉 | K230D 视觉开发板（开发中，配有 ESP32 备选方案） |

## 开源项目说明

本项目在开发过程中使用了以下开源项目，在此完整说明：

| 项目名称 | 作者 / 组织 | 用途 | 许可证 | 链接 |
| --- | --- | --- | --- | --- |
| STM32-HAL-PS2-Library | MR-Addict | PS2 手柄 SPI 通信时序与按键、摇杆数据解析 | 仓库未声明许可证（No License） | https://github.com/MR-Addict/STM32-HAL-PS2-Library |
| STM32Cube HAL 库及 FreeRTOS 中间件 | STMicroelectronics | 主控底层外设驱动与实时操作系统 | 随 CubeMX 生成的 ST 许可声明，版权信息保留在工程各文件头部 | https://www.st.com/ |

使用说明：

*   PS2 库以源码形式导入工程（`ps2.c`、`ps2.h`）。使用中在 `ps2.h` 中补齐了 MOSI、MISO、SCK、SS 的引脚宏映射，并将 `delay_us` 的延时参数由 8 调整为 15，以适配我们使用的接收器；其余未修改库的核心逻辑。
*   上述 PS2 库的仓库未声明开源许可证，我们保留了原作者的版权信息与仓库链接，并在此如实标注。
*   PCA9685 驱动、底盘电机控制与运动学解算、机械臂控制逻辑均为团队自行编写，未使用第三方库。
