# Noname

**CRTC-Noname战队中期考核日志**

## 项目介绍

该项目主要记录了重庆大学2026CRTC赛事中Noname战队的机器人开发日志与源文件。我们基于“抓取并获得更多能量块”的目的，分机械组与电控组两个方向推进，自行设计并制作遥控战车，并按机器人的具体功能分板块记录开发过程。

## 机器人简介

参赛机器人以 STM32F103C8T6 为主控，通过 PS2 无线手柄遥控，在比赛场地内收集并携带能量单元与能量核心。底盘与机械臂经历过一次整体换代：早期试过麦轮配六舵机，最终定型为 65mm 胶轮配三舵机，并在胶轮车的基础上提供加装 K230D 视觉模块的版本。

## 主要配置

各车型的配置：

| 车型 | 底盘 | 机械臂 | 视觉 | 当前状态 |
| --- | --- | --- | --- | --- |
| 麦轮车 | 麦克纳姆轮 | 六舵机 | 无 | 已拆解，底盘与机械臂整体换代为胶轮车 |
| 胶轮车 | 65mm 胶轮 ×4 | 三舵机 + 底座旋转 | 无 / K230D | 已装车，联调中；视觉部分仍在开发 |

各车型统一采用同一套主控与遥控方案：

| 部分 | 方案 |
| --- | --- |
| 主控 | STM32F103C8T6 核心板 |
| 电机驱动 | DRV8833 |
| 舵机驱动 | PCA9685 十六路 PWM 驱动板 |
| 遥控 | PS2 无线手柄，软件 SPI（PB12~PB15） |
| 供电 | 一组 7.4V 18650 电池组，板载 XL4015 分路降压 |
| 视觉 | K230D 视觉开发板 + 机械臂侧方视摄像头 |

## 开源项目说明

本项目在开发过程中使用了若干开源项目，用于机器人的制作与代码编写。各篇实际使用的项目、作者、许可证与修改说明，已分别列在对应文档末尾的「开源项目说明」中：

*   [电控篇 · 开源项目说明](电控篇.md#开源项目说明)：PS2 手柄驱动库、STM32Cube HAL 与 FreeRTOS 中间件。
*   [视觉篇 · 开源项目说明](视觉篇.md#开源项目说明)：K230 参考工程、YOLO、nncase、标注工具与实训战队知识库。
*   机械篇未使用开源项目，结构建模使用商业软件 Autodesk Fusion 360。

其中 STM32-HAL-PS2-Library 与 hyper152/K230 两个仓库**未声明开源许可证**，我们保留了原作者的版权信息与仓库链接，并在各篇中如实标注。除上述项目外，底盘、机械臂与视觉的核心控制逻辑均为团队自行编写，未使用其他第三方库。
