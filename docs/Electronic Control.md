
# 分工三：遥控（PS2 手柄通信）

## 1. 通信协议配置与工程导入
我们的遥控单元采用 **PS2 无线手柄及接收器**，通信接口分配为 **软件 SPI（STM32 的 PB12~PB15 引脚）**。开发初期，将底层驱动库 `ps2.c` 导入工程后，因第三方库依赖 CubeMX 的 User Label，导致引脚宏定义缺失。我们在 `ps2.h` 中手动补齐了 MOSI、MISO、SCK、SS 的引脚宏映射，解决了编译报错。

## 2. 时序调试与数据读取
联调时，我们原有的 `delay_us(8)` 时序对于现有的低成本接收器而言过快，导致无法正常读取数据，所以我们将其修改为了 `delay_us(15)`。

操作层面，通过排查我们发现了**手柄必须按下 Mode 键（红灯/绿灯常亮）才能输出 0~255 的平滑摇杆数据**，后续将此作为遥控操作的标准前置动作。

## 3. 数据解算与电机驱动整合
在通信打通后，我们将手柄数据与电机控制进行了整合。控制逻辑为：在 `while(1)` 循环中以 **20ms 的周期刷新手柄数据**，读取左摇杆垂直轴（LY）模拟量，减去中心值（128）得到偏移量。

为了防止摇杆静止时的微小偏移影响电机，我们将偏移量在 **-10 到 10** 之间的数据全部视为了 0，作为**死区处理**；并将有效偏移量设定为在 -100 到 100 区间的速度值，确定了小车正常的移速区间，调用底层的电机驱动函数，实现了左摇杆对底盘的前后移动与速度的直接控制。

## 4. 基础手动功能设置
在机械臂的操作上，我们将手柄功能键与末端执行器进行了直接映射：
- **三角键**：直接控制机械爪的夹取与松开。
- **方形键 / 圆形键**：控制机械臂底座的逆时针 / 顺时针旋转。
- **叉键**：控制夹取头旋转 90 度。

**设计逻辑**：通过将机械臂的夹取、底座旋转和夹头旋转分别映射到不同按键，我们保证了功能操作的独立性。操作手在抓取时，左手负责底盘，右手负责机械臂，实现左右手分工明确、互不干扰，有效减少了比赛中的操作失误。

## 5. 后续规划
目前我们已跑通基础的手动遥控与底盘控制。后续我们计划在视觉方面继续完善，通过引入摄像头模块，**实现检测到能量块后自动抓取的功能**，向半自动化作业迈进。
